## What makes a good KB article

Each of these follows the same shape: **who it's for**, how to **tell this problem apart** from things it resembles, the **fix in order**, when to **escalate**, and how to **prevent a repeat**. That structure is deliberate — it's what lets a Tier-1 agent resolve something confidently the first time they see it.
